# Frontend (หน้าบ้าน)

This folder contains the web user interface used to present system data to users.

## Main purpose
- display real-time sensor values
- display history charts and export options
- display sky images and cloud-processing results
- display short-term solar power forecasting results

## Important files
- `src/pages/Dashboard.tsx` main dashboard page
- `src/pages/History.tsx` historical analysis page
- `src/App.tsx` route entry point
- `src/lib/` shared frontend helpers

## Notes
This folder is the **frontend / หน้าบ้าน** part of the project.  
It is intentionally kept separate from backend logic and Raspberry Pi runtime code for clarity when cited in the thesis.
